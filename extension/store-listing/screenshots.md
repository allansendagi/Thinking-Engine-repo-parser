# Screenshots — shot list

Chrome Web Store accepts 1–5 screenshots, **1280×800** or 640×400 PNG (1280×800 preferred).
No device frames, no added marketing text baked in beyond a thin caption bar if any. Keep them
literal — the store penalises mockups that don't match the product.

Shoot on a clean Chrome profile with the Thread Mac app paired and ~6 real ideas captured.

1. **Side panel — idea list.** Right side panel open next to a ChatGPT tab. Shows "Open loops"
   and "Current ideas" with real titles. This is the core value in one frame.

2. **Side panel — one idea's evolution.** An idea opened: current formulation at top, the
   evolution steps beneath, one open loop. Shows "recall the thought, not the chat".

3. **The return nudge.** A claude.ai tab with the small "continue where you left off" card
   visible near the composer. Crop tight so the card is the subject.

4. **The popup — connected.** Toolbar popup showing the green "Connected to Thread for Mac"
   state. Small, honest, shows the setup is trivial.

5. *(optional)* **Search.** Side panel with a query typed and 2–3 results — proves ideas are
   retrievable, not just logged.

Export: macOS `⌘⇧4` → space → click the window, then `sips -c 800 1280 shot.png` if the capture
isn't already 1280×800, or resize the Chrome window to 1280×800 first with a window-size tool.
